## 🛡️ STABİLİTE STANDARTLARI

### 1. Gelen Kutusu (Admin Inbox)
- **Yapı:** `table-layout: fixed !important`.
- **Genişlik Koruması:** `width: 100% !important`.
- **Hücre Davranışı:** `overflow: hidden`, `text-overflow: ellipsis`, `white-space: nowrap`.
- **Kritik Genişlikler:**
  - Status: `110px`
  - Sender: `%20`
  - Date: `110px`
  - Actions: `100px`

### 2. Güvenlik Geçidi (Gateway)
- **Konumlama:** Uyarı mesajı panel İÇİNDE, en üstte (`panel.insertBefore(warning, panel.firstChild)`).
- **Animasyon:** `shake-fix` kullanılmalı (Flexbox uyumlu).
- **Mesaj Stili:** `w-full mb-4`, `backdrop-blur-md`, `rounded-full`.

## 🛠️ TEKNİK FORMÜLLER (GERİ DÖNÜŞ KODLARI)

### Gateway Warning JS Logic:
```javascript
function showAttemptWarning(attemptsLeft) {
    const panel = document.getElementById('main-panel');
    const warning = document.createElement('div');
    warning.className = 'warning-toast w-full mb-4 bg-red-500/10 backdrop-blur-md border border-red-500/20 text-red-500 px-4 py-2 rounded-full animate-bounce flex items-center justify-center gap-2';
    panel.insertBefore(warning, panel.firstChild);
}
```
