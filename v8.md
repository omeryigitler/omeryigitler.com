# System Version V8: Radical UI & Global Intelligence Update
**Status:** Operational / Active
**Date:** 2026-01-11

## Overview
This version represents a total transformation of the visitor tracking interface and security protocols, introducing high-end visual aesthetics (Radical UI) and advanced AI-driven command logic.

## Key Improvements

### 1. Radical UI Integration (Taurus v5)
- **Visuals:** Total redesign of the tracker overlay focusing on high-end glassmorphism, animated grids, and pulsating radial glows.
- **Centering:** Achieved perfect viewport vertical and horizontal centering using strict flexbox mathematical alignment.
- **Branding:** Large-scale Taurus logo (2x) as the primary focus in high-alert modes.

### 2. Strict Interaction Lockout
- **Security:** Implemented a hardware-level interception layer for all sensitive modes (`BLOCK`, `FREEZE`).
- **Control:** All inputs (keyboard, mouse, touch, scroll, zoom) are captured and neutralized at the window level, ensuring a total lockout on all devices (Desktop & Mobile).

### 3. Multimodal AI Integration (Gemini v2.5)
- **Feature:** Introduced Voice-to-Command logic using Google Gemini AI.
- **Logic:** Admins can send voice messages via Telegram to trigger system modes (`ALARM`, `BLOCK`, `FREEZE`, `CLEAR`).
- **Intelligent Parsing:** The AI understands natural language (Turkish/English) and can extract dynamic display messages for the Freeze screen.

### 4. Localization & Global Standardization
- **Change:** Switched all system feedback, AI acknowledgments, and error messages to **Strict English**.
- **Reasoning:** Aligning the system with international security standards and ensuring a professional, unified interface.

### 5. Freeze Mode & Dynamic Display
- **Feature:** A dedicated "Freeze" mode that locks the target screen and displays arbitrary messages.
- **Alignment:** Custom messages are mathematically centered and positioned with extreme clearance (18rem) from animations to ensure visual clarity.

### 6. Graceful Quota & Error Management
- **Optimization:** Implemented robust English error handling for API limits (429) and model availability (404).
- **UX:** Users now receive clear instructions (e.g., "Quota Exceeded - Wait 10s") instead of raw JSON data, improving operational reliability.
