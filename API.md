# API Documentation

## 📊 Firestore Collections

### `clients`

**Purpose**: Customer/client records with aggregate statistics

**Document ID**: Email-based hash (deterministic, prevents duplicates)

**Schema**:
```javascript
{
  // Identity
  name: string,                    // Client full name
  email: string,                   // Email (unique, indexed)
  phone: string | null,            // Phone number (optional)
  company: string | null,          // Company name (optional)
  
  // Timestamps
  createdAt: Timestamp,            // First contact date
  lastContactDate: Timestamp,      // Most recent interaction
  
  // Aggregate Statistics
  totalMessages: number,           // Count of messages
  totalQuotes: number,             // Count of quotes
  totalProjects: number,           // Count of projects
  
  // Relationships (arrays of document IDs)
  messageIds: string[],            // References to messages collection
  quoteIds: string[],              // References to quotes collection
  projectIds: string[]             // References to projects collection
}
```

**Indexes**:
- Single field: `email` (ASC)
- Composite: `email ASC, lastContactDate DESC`

### `messages`

**Purpose**: Contact form submissions from public website

**Document ID**: Auto-generated by Firestore

**Schema**:
```javascript
{
  // Client info
  clientId: string,                // Reference to clients/{id}
  name: string,                    // Sender name
  email: string,                   // Sender email
  phone: string | null,            // Phone (optional)
  company: string | null,          // Company (optional)
  
  // Message content
  message: string,                 // Message body
  subject: string | null,          // Subject (optional)
  
  // Metadata
  timestamp: Timestamp,            // Submission time
  ip: string | null,               // Sender IP (masked)
  userAgent: string | null,        // Browser info
  
  // Status tracking
  status: string,                  // 'unread' | 'read' | 'quoted' | 'project-created'
  
  // Relationships
  quoteId: string | null,          // Reference to quotes/{id} (if quote created)
  projectId: string | null         // Reference to projects/{id} (if project created)
}
```

**Indexes**:
- Single field: `timestamp` (DESC)
- Composite: `clientId ASC, timestamp DESC`
- Composite: `status ASC, timestamp DESC`

### `quotes`

**Purpose**: Generated pricing quotes for potential projects

**Document ID**: Auto-generated by Firestore

**Schema**:
```javascript
{
  // Quote identification
  quoteNumber: string,             // Format: Q-2026-001 (sequential)
  
  // Client info
  clientId: string,                // Reference to clients/{id}
  clientName: string,              // Client full name
  clientEmail: string,             // Client email
  
  // Pricing details
  country: string,                 // 'TR' | 'MT' | others
  currency: string,                // 'TRY' | 'EUR'
  siteType: string,                // 'E-Commerce' | 'Corporate' | 'Landing Page'
  pageCount: number,               // Number of pages
  totalPrice: number,              // Final calculated price
  
  // Detailed breakdown
  breakdown: {
    items: [{
      name: string,
      description: string,
      price: number
    }],
    subtotal: number,
    discount: number,
    tax: number
  },
  
  // Status tracking
  status: string,                  // 'draft' | 'sent' | 'accepted' | 'rejected'
  createdAt: Timestamp,            // Quote creation time
  sentAt: Timestamp | null,        // When sent to client
  
  // Relationships
  messageId: string | null,        // Reference to messages/{id} (if from message)
  projectId: string | null,        // Reference to projects/{id} (if accepted)
  
  // Output
  pdfUrl: string | null,           // Firebase Storage URL (if generated)
  notes: string                    // Internal notes
}
```

**Indexes**:
- Single field: `quoteNumber` (ASC)
- Composite: `clientId ASC, createdAt DESC`
- Composite: `status ASC, createdAt DESC`

## 🔧 Core Workflow Functions

### `getOrCreateClient(email, name, additionalData)`

**Purpose**: Atomic client creation/retrieval (race-condition safe)

**Parameters**:
- `email` (string): Client email address
- `name` (string): Client full name
- `additionalData` (object): Optional `{phone, company}`

**Returns**: `Promise<{id: string, data: Object}>`

**Implementation**:
```javascript
async function getOrCreateClient(email, name, additionalData = {}) {
  const normalizedEmail = email.toLowerCase().trim();
  const clientDocId = btoa(normalizedEmail).replace(/[^a-zA-Z0-9]/g, '_');
  const clientRef = db.collection('clients').doc(clientDocId);
  
  return await db.runTransaction(async (transaction) => {
    const doc = await transaction.get(clientRef);
    
    if (doc.exists) {
      return { id: doc.id, data: doc.data() };
    }
    
    const newClient = { /* ... */ };
    transaction.set(clientRef, newClient);
    return { id: clientDocId, data: newClient };
  });
}
```

**Thread-Safe**: ✅ Uses Firestore transactions

### `updateClientStats(clientId, type, itemId)`

**Purpose**: Increment client statistics and update relationships

**Parameters**:
- `clientId` (string): Client document ID
- `type` (string): 'message' | 'quote' | 'project'
- `itemId` (string): Document ID of created item

**Returns**: `Promise<void>`

**Side Effects**:
- Increments `totalMessages`, `totalQuotes`, or `totalProjects`
- Appends `itemId` to corresponding array (`messageIds`, `quoteIds`, `projectIds`)
- Updates `lastContactDate`

---

### `saveQuoteToFirestore(quoteData, messageId)`

**Purpose**: Create new quote document with full linkage

**Parameters**:
- `quoteData` (object): Quote details from pricing tool
- `messageId` (string | null): Optional message reference

**Returns**: `Promise<string>` (quote document ID)

**Workflow**:
1. Call `getOrCreateClient()` for client
2. Generate sequential quote number via `getNextQuoteNumber()`
3. Create quote document
4. Call `updateClientStats(clientId, 'quote', quoteId)`
5. If `messageId` provided, update message with `quoteId` and status='quoted'

---

### `saveProjectToFirestore(projectData)`

**Purpose**: Create new project with linking

**Parameters**:
- `projectData` (object): Project details

**Returns**: `Promise<string>` (project document ID)

**Workflow**:
1. Call `getOrCreateClient()`
2. Generate project number via `getNextProjectNumber()`
3. Create project document
4. Call `updateClientStats(clientId, 'project', projectId)`
5. If `quoteId` exists, update quote status='accepted'
6. If `messageId` exists, update message status='project-created'

---

### `getClientHistory(clientId)`

**Purpose**: Fetch complete client interaction timeline

**Parameters**:
- `clientId` (string): Client document ID

**Returns**: `Promise<{messages: [], quotes: [], projects: []}>`

**Implementation**:
```javascript
async function getClientHistory(clientId) {
  const [messagesSnap, quotesSnap, projectsSnap] = await Promise.all([
    db.collection('messages').where('clientId', '==', clientId).get(),
    db.collection('quotes').where('clientId', '==', clientId).get(),
    db.collection('projects').where('clientId', '==', clientId).get()
  ]);
  
  return {
    messages: messagesSnap.docs.map(d => ({id: d.id, ...d.data()})),
    quotes: quotesSnap.docs.map(d => ({id: d.id, ...d.data()})),
    projects: projectsSnap.docs.map(d => ({id: d.id, ...d.data()}))
  };
}
```

## 🔢 Sequential Numbering

### Quote Numbers

**Format**: `Q-YYYY-NNN` (e.g., `Q-2026-001`)

**Implementation**:
```javascript
async function getNextQuoteNumber() {
  const statsRef = db.collection('stats').doc('counters');
  
  return await db.runTransaction(async (transaction) => {
    const doc = await transaction.get(statsRef);
    const year = new Date().getFullYear();
    const currentYear = doc.data()?.quoteYear || 0;
    
    let nextNumber = 1;
    if (currentYear === year) {
      nextNumber = (doc.data()?.quoteCounter || 0) + 1;
    }
    
    transaction.set(statsRef, {
      quoteYear: year,
      quoteCounter: nextNumber
    }, {merge: true});
    
    return `Q-${year}-${String(nextNumber).padStart(3, '0')}`;
  });
}
```

---

### Project Numbers

**Format**: `PR-YYYY-NNN` (e.g., `PR-2026-001`)

**Implementation**: Similar to quote numbering, using `projectYear` and `projectCounter` fields.

## 📡 Real-Time Listeners

### Messages Listener

```javascript
db.collection('messages')
  .orderBy('timestamp', 'desc')
  .onSnapshot(snapshot => {
    snapshot.docChanges().forEach(change => {
      if (change.type === 'added') {
        // New message notification
        showNotification('New message received');
      }
    });
  });
```

### Clients Listener

```javascript
db.collection('clients')
  .orderBy('lastContactDate', 'desc')
  .onSnapshot(snapshot => {
    // Update client list in real-time
    renderClientsTable(snapshot.docs);
  });
```
